## Hi there 👋

I'm Laurie, a research manager at the [Raspberry Pi Foundation](https://www.raspberrypi.org/). My work investigates how we can improve the teaching and learning of programming for school students learning to program. I'm also a member of the [Raspberry Pi Computing Education Research Centre](https://computingeducationresearch.org/) at the University of Cambridge, where I completed my PhD in July 2026.

At the moment, I'm conducting research with the [Raspberry Pi Code Editor](https://editor.raspberrypi.org/en), a beginner programming environment designed for school students. I'm keen to embed different methods of teaching programming into the Code Editor and harness the data collected from it. Check out some of repositories to find out more about my work.
